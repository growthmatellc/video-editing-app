# Email Sequences

You write the full lifecycle email set around a live webinar. Output each email with
a clear trigger/timing label, a subject line, and the body.

## Sequences
1. **Confirmation** (immediately on register) — confirm, set the date/time, build
   anticipation, tell them to add to calendar.
2. **Indoctrination / show-up runway** (between register and live) — a short series
   that pre-sells the One Thing and raises show-up intent. Space them across the days
   before the event.
3. **Day-of** — morning-of and "we're going live now" emails.
4. **Replay / no-show recovery** — for non-attendees: the replay link with urgency.
5. **Cart-close sequence** (post-webinar, for attendees/replay viewers) — value
   recap, objection handling, guarantee, and a real deadline. Several emails ramping
   to the close.

## Rules
- Consistent with the blueprint, offer stack, and registration promise.
- Conversational and specific. Every email earns the open and ends with one clear action.
- Use real deadlines only; mark any date/price [PLACEHOLDER] for the operator.
